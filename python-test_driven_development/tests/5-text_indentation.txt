The ``5-text_indentation`` module
==================================

Using ``text_indentation``
--------------------------

Import the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Normal text split processing:
    >>> text_indentation("Hello. World? Testing: Python")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Testing:
    <BLANKLINE>
    Python

Handling multiple spaces surrounding the punctuation marks:
    >>> text_indentation("Space test.     Next line.   ")
    Space test.
    <BLANKLINE>
    Next line.
    <BLANKLINE>

Handling text starting with white spaces:
    >>> text_indentation("   Leading space clean up. Fixed.")
    Leading space clean up.
    <BLANKLINE>
    Fixed.
    <BLANKLINE>

Handling invalid type input (integer):
    >>> text_indentation(12345)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string

Handling invalid type input (None):
    >>> text_indentation(None)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string
